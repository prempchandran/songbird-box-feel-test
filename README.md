# The Songbird Box: hand-interaction feel test

A WebXR prototype for testing pinch-to-grab, two-hand scaling, snapping parts together and pulling them apart, pin / fixed / rail joints, meshing gears and motion trails, in passthrough on a Meta Quest.

Open the GitHub Pages link in the Quest browser and press **Enter mixed reality**. On a computer it runs as a mouse-driven preview.

Uses [three.js](https://threejs.org) r160 (MIT licence), included as `three.module.min.js`.
